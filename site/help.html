Help

Known problems, all seen while building and testing this, with what fixes them.

Starting and connecting

You seeCause and fix
Port 38281 is already in use from the start script An old MultiServer is still running. Close its console window, or start with -Port 38282.
"Connect the AP client" when opening the area menu The BizHawk Client is not connected (or BizHawk was reset). Start it from the Archipelago Launcher or rerun the start script; the menu works as soon as the client has written to the game.
BizHawk Client log: "TMNT RAM addresses are unverified placeholders" A leftover warning; the addresses are checked (see docs/research/tmnt-ram.md). Safe to ignore.
Generation hangs with no output Archipelago opened a file dialog for a missing base ROM, possibly behind other windows. Put both ROMs where Setup says.
Universal Tracker never answers Create the folder Archipelago\Players; without it a hidden folder dialog waits.

Start with start.cmd → 3 Check before going live: every FAIL or WARN line says what to do under it.

In the game

You seeCause and fix
"No state for Area N" or "(missing)" in the menu savestates\areaN.State is missing. Make the states (Setup).
"Could not load Area N" The state was made in another BizHawk version. Make the states again in this one.
The menu opened by itself and B does nothing You beat a boss and the next Area is locked, or a new game started. Load an unlocked Area.
A turtle I rescued in the game got captured again You do not own her yet in Archipelago. Find her item.
The turtle on screen still has Leo's colours after a switch Only the sprite colours lag; pause and unpause, or walk into the next room.
The run ended on the title screen after a game over The seed is older than the unlimited-continues patch. Generate a new seed.
"Game swap: start tools\game_swap.py" after Select+Start The game swap window is closed. Start it again: .venv\Scripts\python.exe tools\game_swap.py.
Select+Start pauses but the other game does not come up Look in the game swap window. "no ... window": that BizHawk is closed or has no game loaded. "Windows did not let ... come to the front": click the window once; it happens when another program holds the focus.
BizHawk crashed while playing A Link to the Past Start the session again (start.cmd → 2, same seed). The start puts BizHawk's autosave back, at most a minute old; the start window says "using BizHawk's autosave of ...". Then load the file in the game.
A Link to the Past shows another seed's save file Start sessions with start.cmd, which gives each seed its own save. Old saves are kept as alttp-stream.<seed>.SaveRAM in BizHawk's SNES\SaveRAM folder.
No "Zelda got ..." / "TMNT got ..." notices They show only in the game in front, for items of the game behind, at the bottom left for two seconds. The game swap window says "items: watching the server" when they are on.
"controller swap stopped" in the game swap window That game's BizHawk closed or its Lua scripts stopped. Restart it with its session file (lua\alttp_stream.luases or lua\tmnt_stream.luases).

On stream

You seeCause and fix
PopTracker is a black box in OBS Set "software_renderer": true in %APPDATA%\PopTracker\PopTracker.json and restart PopTracker.
A BizHawk or tracker capture is empty The window title is not the expected one. Start the games with tools\start_stream.ps1 (it gives the fixed titles), or pick the window by hand in the source's properties.
The panel says "No server"The server is not running, or the URL's server= is wrong. It reconnects by itself every 5 seconds.
The panel says "Game not in this seed"The slot name in the URL does not match the seed.
PopTracker asks "Check for PopTracker updates on start?" and does not connect PopTracker broke its own settings file when it last closed. Answer No, or stop and start the session with start.cmd: the start repairs the file ("repaired PopTracker's settings file").
OBS does not follow the game The game swap window says why. "OBS not reachable": turn on Tools → WebSocket Server Settings → Enable WebSocket server. "left as it is": OBS shows a scene other than Hyrule or New York, which the swap never changes.
"Click the blue silhouette below for onboarding" on screen BizHawk 2.11's own hint; click it away once.

Emergency

If a check is lost or a softlock happens live, the host can type in the server console: /send Turtles <item> or /send_location Turtles <location>. Bosses can always be played again from the area menu, and nothing in TMNT can be missed for good (see docs/research/tmnt-softlock-risks.md).
