How it works

  • TMNT world (apworld/tmnt): items, locations, rules, options and a ROM patch (an AP tag plus unlimited continues).
  • BizHawk client (client.py, logic in client_logic.py): reads the game's RAM and a small mailbox at $0388, sends checks, and writes turtles' HP, packs and the pass mask.
  • Area menu (lua/tmnt_area_select.lua): loads one savestate per Area, counts loads in the mailbox so the client syncs, watches for boss wins, continues and new games, and draws the HUD.
  • A Link to the Past: Archipelago's own world through SNI, unchanged.
  • Game swap (lua/game_swap.lua in both BizHawk, tools/game_swap.py): Select+Start writes a token to output\swap\<system>-request.txt; the helper answers in -ack.txt, brings the other window to the front and, through obs-websocket 5, switches OBS to that game's scene. It also watches the server as a Tracker and writes <system>-notice.txt for the game in front; the area menu writes NES-event.txt when the client opens a new pass.
Mailbox byteWritten byMeaning
$0388clientPass mask: bit N-1 = Area N playable, bit 5 = Technodrome
$0389menuLoad counter (1-255; 0 = nothing loaded)
$038AclientAck of the load counter (full sync done)
$038BclientMagic A7: the client is there
$038CclientOwned items for the HUD
$038DclientBosses the server has as checked
$038EmenuWins the menu saw (bosses, Shredder), for a client that was away

Tests

:: unit tests (logic, client, ROM patch)
cd Archipelago
..\.venv\Scripts\python.exe -m unittest discover -s worlds\tmnt\test -t .
cd ..

:: many seeds
.venv\Scripts\python.exe tools\gen_many.py --count 100 --players players\ --ap Archipelago\

:: game swap, notices and save handling (stand-in OBS and server, no BizHawk needed)
.venv\Scripts\python.exe -m unittest discover -s tools -p test_*.py

:: area menu in BizHawk, writes savestates\area_select_test\result.txt
apps\BizHawk-2.11.1\EmuHawk.exe --lua=%CD%\lua\tmnt_area_select_test.lua "roms\Teenage Mutant Ninja Turtles (USA).nes"

:: swap script in BizHawk (any NES or SNES game), writes savestates\game_swap_test\<system>-result.txt
apps\BizHawk-2.11.1\EmuHawk.exe --lua=%CD%\lua\game_swap_test.lua "roms\Teenage Mutant Ninja Turtles (USA).nes"

:: the whole chain: server, BizHawk, menu and client, scripted
.venv\Scripts\python.exe tools\e2e_run.py --seed-zip output\e2e\AP_<seed>.zip --rom output\e2e\<patched>.nes

Last run (2026-10-31): 135 unit tests, area menu 40/40, end-to-end run passing, 150 seeds generated without errors; tools 32 unit tests, area menu 42/42, swap script 11/11 in BizHawk for NES and SNES, and a whole session started, checked (all OK) and stopped through start.cmd, with live item notices and OBS 32.2.2 following every swap.
