Setup

One-time installation on the streaming PC (Windows 10/11). You need your two ROMs and OBS; the installer takes care of everything else.

Install in one go

  1. Get this repo: Code → Download ZIP on GitHub and unzip it (for example to C:\tmntalttp), or git clone it. A short path without spaces is best.
  2. Double-click install.cmd. It asks for your two ROMs in a file dialog (see ROMs) and checks them.
  3. Wait. The first run downloads about 200 MB and installs Archipelago's Python packages, which takes a few minutes. BizHawk opens by itself for about half a minute to make the TMNT area savestates.
  4. Answer Y to add the scene collection to OBS (OBS must be closed for that), then generate a seed and start playing as on Play.

Every download is pinned to a version and checked against a SHA-256 sum. Downloads are kept in .cache\downloads; running install.cmd again skips what is already installed, so it is also the way to repair an install. It also sets PopTracker to software rendering (needed for OBS capture) and turns off its first-start questions, and ends by running the TMNT tests and generating three test seeds.

Without dialogs, for example from a script:

powershell -ExecutionPolicy Bypass -File install.ps1 -AlttpRom D:\roms\zelda.smc -TmntRom D:\roms\tmnt.nes -Yes
BizHawk needs its prerequisitesIf BizHawk does not start, install .NET Framework 4.8 and the Visual C++ 2015-2022 x64 runtime (most streaming PCs already have both).

ROMs

You bring your own dumps. The installer checks the md5, removes a copier header from the ALttP dump and copies them where they are needed. They never go into git.

Teenage Mutant Ninja TurtlesNES, USA, clean iNES header, 262 160 bytes 5e24ccd733d15e42d847274e7add0a76 roms\Teenage Mutant Ninja Turtles (USA).nes and a copy in Archipelago\

A .smc dump of ALttP usually has a 512-byte copier header (1 049 088 bytes). The installer strips it; by hand:

python -c "d=open('roms/Zelda no Densetsu.smc','rb').read()[512:]; open('Archipelago/Zelda no Densetsu - Kamigami no Triforce (Japan).sfc','wb').write(d); import hashlib; print(hashlib.md5(d).hexdigest())"
Why both places for TMNT?The tools in lua\ read roms\; Archipelago looks for the base ROM next to itself when it patches a seed.

Manual install

Only if you cannot use the installer: the same steps by hand. The start script looks for BizHawk and PopTracker in apps\ first and then in %USERPROFILE%\Downloads\; both can also be passed as parameters.

Code and Archipelago

  1. Clone this repo and Archipelago at the pinned tag: 
    git clone https://github.com/moggenswe/alttptmnt.git C:\Project\tmntalttp
cd C:\Project\tmntalttp
git clone https://github.com/ArchipelagoMW/Archipelago.git Archipelago
git -C Archipelago checkout 0.6.8
  2. Make the venv and install Archipelago's requirements: 
    py -3.12 -m venv .venv
cd Archipelago
..\.venv\Scripts\python.exe ModuleUpdate.py --yes
cd ..
  3. Link the TMNT world into Archipelago (in cmd; a junction, so edits in apworld\tmnt apply at once): 
    mklink /J Archipelago\worlds\tmnt apworld\tmnt

BizHawk and SNI

  1. Unzip BizHawk 2.11.1 to apps\BizHawk-2.11.1\. BizHawk runs both games: TMNT on its NES core, ALttP on its SNES core.
  2. Unzip SNI into Archipelago\SNI\ so that Archipelago\SNI\sni.exe exists. SNI's lua\Connector.lua is what BizHawk runs for ALttP.
Use one BizHawk version everywhere.The area savestates only load in the BizHawk version that made them. If the stream PC uses another version, make the states again there (next step).

Area savestates

The in-game area menu loads one savestate per TMNT Area. Make them once, in the BizHawk that will be used live:

apps\BizHawk-2.11.1\EmuHawk.exe --lua=%CD%\lua\tmnt_make_area_states.lua "%CD%\roms\Teenage Mutant Ninja Turtles (USA).nes"

It writes savestates\area1.State … area6.State with a screenshot next to each. A patched seed ROM can load states made from the clean ROM.

Trackers

  1. Unzip PopTracker to apps\PopTracker-0.36.0\ and put the ALttP pack zip into its packs\ folder.
  2. Build and install the TMNT pack (made from the TMNT world's own tables): 
    .venv\Scripts\python.exe tools\make_poptracker_pack.py --install
  3. Start PopTracker once, then set these in %APPDATA%\PopTracker\PopTracker.json: 
    "software_renderer": true,
"check_for_updates": false,
"add_emo_packs": false
    software_renderer is required for OBS.With the hardware renderer, OBS window capture shows PopTracker as a black box.
  4. Optional: put tracker.apworld in Archipelago\custom_worlds\ and create an empty folder Archipelago\Players (Universal Tracker hangs on a hidden dialog without it).

OBS

Build the scene collection (absolute paths for this PC) and import it in OBS under Scene Collection → Import:

.venv\Scripts\python.exe tools\make_obs_collection.py

The file is tools\obs\tmnt-alttp-scenes.json. See Stream for the scenes.

Check the install

cd Archipelago
..\.venv\Scripts\python.exe -m unittest discover -s worlds\tmnt\test -t .
cd ..
.venv\Scripts\python.exe tools\gen_many.py --count 20 --players players\ --ap Archipelago\

Expect OK from the tests and ok=20 failed=0 from the generator. Then generate a seed and start everything as on Play.
