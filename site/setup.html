Setup

One-time installation on the streaming PC (Windows 10/11). Paths below are the ones the start script expects; every one of them can be changed with a parameter.

You bring your own dumps. They never go into git (the repo ignores *.nes, *.sfc, *.smc).

A .smc dump of ALttP usually has a 512-byte copier header (1 049 088 bytes). Strip it and check:

python -c "d=open('roms/Zelda no Densetsu.smc','rb').read()[512:]; open('Archipelago/Zelda no Densetsu - Kamigami no Triforce (Japan).sfc','wb').write(d); import hashlib; print(hashlib.md5(d).hexdigest())"
Why both places for TMNT?The tools in lua\ read roms\; Archipelago looks for the base ROM next to itself when it patches a seed.

Code and Archipelago

  1. Clone this repo and Archipelago at the pinned tag: 
    git clone https://github.com/moggenswe/alttptmnt.git C:\Project\tmntalttp
cd C:\Project\tmntalttp
git clone https://github.com/ArchipelagoMW/Archipelago.git Archipelago
git -C Archipelago checkout 0.6.8
  2. Make the venv and install Archipelago's requirements: 
    py -3.12 -m venv .venv
cd Archipelago
..\.venv\Scripts\python.exe ModuleUpdate.py --yes
cd ..
  3. Link the TMNT world into Archipelago (in cmd; a junction, so edits in apworld\tmnt apply at once): 
    mklink /J Archipelago\worlds\tmnt apworld\tmnt

BizHawk and SNI

  1. Unzip BizHawk 2.11.1 to %USERPROFILE%\Downloads\BizHawk-2.11.1-win-x64\. BizHawk runs both games: TMNT on its NES core, ALttP on its SNES core.
  2. Unzip SNI into Archipelago\SNI\ so that Archipelago\SNI\sni.exe exists. SNI's lua\Connector.lua is what BizHawk runs for ALttP.
Use one BizHawk version everywhere.The area savestates only load in the BizHawk version that made them. If the stream PC uses another version, make the states again there (next step).

Area savestates

The in-game area menu loads one savestate per TMNT Area. Make them once, in the BizHawk that will be used live:

%USERPROFILE%\Downloads\BizHawk-2.11.1-win-x64\EmuHawk.exe --lua=C:\Project\tmntalttp\lua\tmnt_make_area_states.lua "C:\Project\tmntalttp\roms\Teenage Mutant Ninja Turtles (USA).nes"

It writes savestates\area1.State … area6.State with a screenshot next to each. A patched seed ROM can load states made from the clean ROM.

Trackers

  1. Unzip PopTracker to %USERPROFILE%\Downloads\PopTracker-0.36.0\ and put the ALttP pack zip into its packs\ folder.
  2. Build and install the TMNT pack (made from the TMNT world's own tables): 
    .venv\Scripts\python.exe tools\make_poptracker_pack.py --install
  3. Start PopTracker once, then set these in %APPDATA%\PopTracker\PopTracker.json: 
    "software_renderer": true,
"check_for_updates": false,
"add_emo_packs": false
    software_renderer is required for OBS.With the hardware renderer, OBS window capture shows PopTracker as a black box.
  4. Optional: put tracker.apworld in Archipelago\custom_worlds\ and create an empty folder Archipelago\Players (Universal Tracker hangs on a hidden dialog without it).

OBS

Build the scene collection (absolute paths for this PC) and import it in OBS under Scene Collection → Import:

.venv\Scripts\python.exe tools\make_obs_collection.py

The file is tools\obs\tmnt-alttp-scenes.json. See Stream for the scenes.

Check the install

cd Archipelago
..\.venv\Scripts\python.exe -m unittest discover -s worlds\tmnt\test -t .
cd ..
.venv\Scripts\python.exe tools\gen_many.py --count 20 --players players\ --ap Archipelago\

Expect OK from the tests and ok=20 failed=0 from the generator. Then generate a seed and start everything as on Play.
