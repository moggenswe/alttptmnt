Play

Generate a seed, start everything with one command, then play Hyrule and New York until both Ganon and Shredder are beaten.

Generate a seed

The player files are in players\: alttp.yaml (slot Link) and tmnt.yaml (slot Turtles). start.cmd → 1 does this; by hand:

cd C:\Project\tmntalttp\Archipelago
..\.venv\Scripts\python.exe Generate.py --player_files_path ..\players --outputpath ..\output\seeds

The result is output\seeds\AP_<seed>.zip. It holds the server file, both patch files and the spoiler log (with the playthrough). Keep the spoiler with the production team, off screen.

Start a session

start.cmd → 2 runs this script; by hand:

cd C:\Project\tmntalttp
powershell -ExecutionPolicy Bypass -File tools\start_stream.ps1 -Seed output\seeds\AP_<seed>.zip

The script patches the ROMs if needed, looks after A Link to the Past's save (below) and then starts, in order:

  1. MultiServer on localhost:38281, in its own console window (host commands go there).
  2. SNI.
  3. Game swap (tools\game_swap.py) in its own console window; see Switching games.
  4. BizHawk with ALttP and lua\alttp_stream.luases: SNI's Lua connector plus the swap script (window "alttp-stream [SNES] - BizHawk").
  5. BizHawk with TMNT and lua\tmnt_stream.luases: Archipelago's connector, the area menu and the swap script (window "tmnt-stream [NES] - BizHawk").
  6. SNI Client and BizHawk Client, already connected.
  7. Two PopTracker windows: ALttP (slot Link) and TMNT (slot Turtles).

It stops if port 38281 is already in use. Parameters: -Port, -AlttpSlot, -TmntSlot, -EmuHawk, -PopTracker, -NoTracker, -SwapHotkey (default ctrl+shift+space, none for no key) and -NoObsSwitch (the swap leaves OBS alone).

A Link to the Past's save

Before BizHawk starts, tools\bizhawk_saves.py makes sure of three things:

  • Autosave every minute. BizHawk normally writes the save to disk only when it closes, so a crash would lose the whole session. The script turns on BizHawk's own autosave.
  • Back after a crash. BizHawk ignores its autosave when an older save file exists, so the script puts the newer autosave in place first (the old file is kept as alttp-stream.SaveRAM.before-recovery).
  • One save per seed. Every seed runs as alttp-stream.sfc, and BizHawk names saves after the ROM. The script parks the last seed's save as alttp-stream.<seed>.SaveRAM and brings this seed's back, so a new seed never opens an old seed's file.

TMNT keeps no save of its own: its progress is on the server and in the area savestates.

Switching games

Both games run all the time, each in its own BizHawk window; the controller drives the window in front. To switch:

PressWhat happens
Select+Start on the controllerThe game you leave pauses (Start), the other game's window comes to the front and OBS switches to its scene with the pizza-wipe. Press Start there to play on.
Ctrl+Shift+Space on the keyboardThe same, without pausing: pause first.
Alt+Tab or a click on a game windowAlso fine: OBS follows whichever game window is in front.

Notices from the game behind. When an item arrives for the other game, the game you are playing says so at the bottom left for two seconds: "Zelda got Hookshot" in TMNT, "TMNT got Rope Pack" in A Link to the Past. When a TMNT Area becomes playable, whichever game you play says "TMNT: Area 3 is open" (or "the Technodrome (GO MODE)"). That is the moment to think about switching.

What the pause looks like: TMNT shows its information screen. A Link to the Past opens the item menu, or, when Select reached the game first, the "Continue / Save and Quit" box with Continue picked; Start goes back to the game from either.

Items keep arriving in the game behind: BizHawk runs in the background ("Run in background" is on, "Accept background input" off, as BizHawk ships). OBS is only switched while it shows Hyrule or New York, so a host's own scene (a break, an interview) stays up. The swap's console window says when each game's script is ready, and logs every swap.

The ALttP side

Standard Archipelago A Link to the Past through SNI: open mode, goal Ganon, vanilla entrances. Its chests hold turtles, passes and packs; TMNT's bosses and entrances hold its items (Hookshot, Flippers and Moon Pearl always do). Crystals are shuffled between dungeons as usual; the runner sees them on the map.
